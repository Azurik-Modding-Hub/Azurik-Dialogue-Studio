# Changelog

## 1.0.0 — Official first release

- Native Windows application with the Perathia Modding Hub icon and French/English interface.
- Read local European Azurik dumps and Xbox ISO/XISO images, with separate EN/FR/DE banks.
- View and replace existing dialogue panels while preserving their frames and continuation prompts.
- Import UTF-8 TXT files or replace complete panels with PNG images at native texture resolution.
- Preview and replace voices, including the oracle recordings, using local integer PCM WAV files.
- Resize native audio resources to fit longer or shorter recordings, without speeding up or truncating speech.
- Adjust imported voice gain with a linked peak limiter and explicitly choose its playback start.
- Save individual PNG/WAV/TXT resources and export sorted libraries for the active language.
- Undo, redo, restore originals and save portable projects with imported PNG images and recordings.
- Export modified banks and build separate ISO images with full file readback validation.

Game files and personal recordings are not distributed. New dialogue-event placement
in Level Studio remains a future feature. Modified game playback still needs testing in Xemu.
